# 📊 Análisis de Cancelación de Clientes (Churn) - Telecom

## 📌 Descripción del Proyecto
Este proyecto tiene como objetivo analizar los factores que influyen en la cancelación de clientes (churn) en una empresa de telecomunicaciones.  
A partir del análisis exploratorio de datos y la aplicación de modelos de machine learning, se busca identificar patrones que permitan predecir qué clientes tienen mayor probabilidad de abandonar el servicio.

El análisis incluye limpieza de datos, exploración estadística, entrenamiento de modelos predictivos y propuestas de estrategias de retención basadas en los resultados obtenidos.
